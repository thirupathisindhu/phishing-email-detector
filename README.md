# Phishing Email Detection System

This project uses NLP and Machine Learning to classify emails as phishing or legitimate.

## Tech Stack
Python
NLTK
Scikit-learn
TF-IDF
Naive Bayes

## Features
- Text preprocessing
- Stopword removal
- TF-IDF vectorization
- Classification model
- Email prediction

## Run

pip install -r requirements.txt
python spam_phishing_detector.py
